### Tujuan Praktikum
Mempelajari penerapan CSS untuk mengatur tampilan halaman web.

### Materi Praktikum
1. Membuat dokumen HTML.
2. Mendeklarasikan CSS Internal.
3. Menambahkan CSS Inline.
4. Membuat CSS Eksternal.
5. Menggunakan ID Selector dan Class Selector.

### Daftar File
- `lab2_css_dasar.html` — dokumen HTML utama.
- `style_eksternal.css` — aturan CSS eksternal.

### Kesimpulan
CSS digunakan untuk mengatur warna, ukuran teks, jarak, garis tepi, dan tata letak halaman web. CSS dapat diterapkan melalui metode Inline, Internal, dan Eksternal.
