### Tujuan Praktikum
Mempelajari penerapan CSS untuk mengatur tampilan halaman web.

### Materi Praktikum
1. Membuat dokumen HTML.
2. Mendeklarasikan CSS Internal.
3. Menambahkan CSS Inline.
4. Membuat CSS Eksternal.
5. Menggunakan ID Selector dan Class Selector.

### Daftar File
- `lab2_css_dasar.html` — dokumen HTML utama.
- `style_eksternal.css` — aturan CSS eksternal.

### Kesimpulan
CSS digunakan untuk mengatur warna, ukuran teks, jarak, garis tepi, dan tata letak halaman web. CSS dapat diterapkan melalui metode Inline, Internal, dan Eksternal.




## Dokumentasi Langkah-Langkah Praktikum

### Langkah 1 — Membuat Dokumen HTML
Pada tahap pertama, dibuat file `lab2_css_dasar.html` sebagai dokumen utama praktikum. Dokumen ini berisi struktur HTML, judul halaman, menu navigasi, paragraf, dan tautan informasi.

**Gambar 1.** Pembuatan dokumen HTML dasar pada Visual Studio Code.

### Langkah 2 — Menerapkan CSS Internal
CSS Internal ditambahkan menggunakan tag `<style>` pada bagian `<head>`. Pengaturan ini digunakan untuk mengubah jenis huruf, warna teks, ukuran judul, perataan teks, dan tampilan elemen halaman.

**Gambar 2.** Penerapan CSS Internal pada dokumen HTML.

### Langkah 3 — Menerapkan CSS Inline
CSS Inline diterapkan langsung pada elemen paragraf menggunakan atribut `style`. Pada tahap ini, properti `text-align` digunakan untuk mengatur perataan teks dan properti `color` untuk mengubah warna teks.

**Gambar 3.** Penerapan CSS Inline pada elemen paragraf dan hasil perubahannya di browser.

### Langkah 4 — Membuat CSS Eksternal
File `style_eksternal.css` dibuat untuk menyimpan aturan CSS secara terpisah dari dokumen HTML. File tersebut kemudian dihubungkan melalui tag `<link>` pada bagian `<head>` dokumen HTML.

**Gambar 4.** Pembuatan dan penghubungan file CSS Eksternal.

### Langkah 5 — Menerapkan ID Selector dan Class Selector
ID Selector menggunakan tanda pagar (`#`) untuk memilih elemen berdasarkan ID, sedangkan Class Selector menggunakan tanda titik (`.`) untuk memilih elemen berdasarkan class. Keduanya digunakan untuk mengatur tampilan area konten dan tombol.

**Gambar 5.** Penerapan ID Selector dan Class Selector pada file CSS Eksternal.

### Langkah 6 — Menguji Hasil di Browser
Setelah kode disimpan, halaman HTML dibuka melalui browser untuk memastikan aturan CSS diterapkan dengan benar. Hasilnya terlihat pada navigasi berwarna hijau, area konten berwarna biru, serta tombol berwarna merah.

**Gambar 6.** Hasil akhir penerapan CSS pada halaman web.

### Langkah 7 — Membuat Halaman HTML Dasar
Sebagai pengembangan tambahan, dibuat file `lab1_tag_dasar.html` yang berisi pengenalan tag HTML, contoh heading, paragraf, tautan, dan navigasi kembali ke halaman CSS Dasar.

**Gambar 7.** Tampilan halaman HTML Dasar sebagai pengembangan proyek.

### Langkah 8 — Membuat Halaman CSS Eksternal
File `css_eksternal.html` dibuat sebagai halaman tambahan untuk menunjukkan penggunaan file `style_eksternal.css`. Halaman ini menampilkan navigasi, area konten, dan tombol untuk kembali ke halaman CSS Dasar.

**Gambar 8.** Tampilan halaman CSS Eksternal yang menggunakan stylesheet terpisah.

### Langkah 9 — Mengunggah Proyek ke GitHub
Seluruh file praktikum disimpan dalam repository GitHub `Lab3Web`. Proses commit dan push dilakukan melalui Source Control di Visual Studio Code agar kode dan dokumentasi proyek tersimpan di repository.

**Gambar 9.** Repository GitHub Lab3Web yang berisi file HTML, CSS, README, dan folder screenshot.
