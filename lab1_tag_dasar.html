Selamat Datang!

HTML adalah bahasa markup yang digunakan untuk menyusun struktur halaman web.

Contoh Tag HTML

1. Heading

Tag heading digunakan untuk membuat judul, misalnya h1, h2, dan h3.

2. Paragraf

Tag p digunakan untuk menampilkan teks dalam bentuk paragraf.

3. Tautan

Tag a digunakan untuk berpindah ke halaman lain.
